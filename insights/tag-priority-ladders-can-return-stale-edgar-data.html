Tag priority ladders can return stale EDGAR data

Omitting modern revenue concepts in SEC EDGAR XBRL fallback ladders causes extraction scripts to return decade-old historical figures rather than reporting missing data.

Core takeaway

Omitting modern revenue concepts in SEC EDGAR XBRL fallback ladders causes extraction scripts to return decade-old historical figures rather than reporting missing data.

Operating models affected

Truckload Brokerage, Asset Carriage / Truckload Fleet, LTL, Domestic Intermodal

Where observed

hub-group, old-dominion, the source recordsource-register

The trap

US-GAAP financial reporting taxonomies evolve over time. Following ASC 606 adoption in 2018, most transport filers transitioned primary top-line disclosures from legacy concepts (like SalesRevenueNet) to modern revenue concepts (such as RevenueFromContractWithCustomerIncludingAssessedTax).

When automated scrapers query the SEC companyfacts API, they traverse an ordered list of fallback tags.

If the primary modern tag is missing from the script's priority list, the parser steps down to older legacy tags. Because historical SEC filings remain permanently stored in the company fact cache, the API returns the last recorded figure under the legacy tag — often from 2017 or 2018.

The script treats this as a valid current retrieval. A stale number wearing an authentic source is far harder to detect than an empty field.

Where it was observed

Documented in source register during programmatic financial extraction across the US filing cohort.

Omitting RevenueFromContractWithCustomerIncludingAssessedTax from the priority sequence caused extraction routines to pull FY2017 and FY2018 revenues for Hub Group, Inc., Old Dominion Freight Line, Inc., J.B. Hunt (JBHT), Marten Transport (MRTN), Covenant Logistics (CVLG), and P.A.M. Transportation (PAMT).

The pipeline extracted figures nearly a decade out of date without triggering an error.

How to spot it

Never accept an extracted XBRL fact without checking the fy, fp, and end fields in the returned JSON unit.

Structure tag priority ladders to query modern ASC 606 revenue concepts first. Validate extracted years against expected fiscal periods before computing metrics in the metric dictionary or evaluating peer models in operating models.
